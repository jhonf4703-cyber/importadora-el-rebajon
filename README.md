# Importadora El Rebajón

Tienda estática lista para publicar en Vercel.

## Funciones
- Catálogo responsive
- Carrito con cantidades y almacenamiento local
- Formulario de pedido
- Pago exclusivamente contra entrega
- Envío del pedido a WhatsApp
- Enlaces a Facebook y WhatsApp
- Buscador
- Diseño negro/naranja

## Antes de publicar
1. Reemplaza las imágenes de `images/` si quieres usar otras.
2. Si cambias el número de WhatsApp, edita `WHATSAPP` en `script.js` (formato internacional, sin + ni espacios).
3. Si quieres cambiar precios o productos, edita el arreglo `products` en `script.js`.
4. La Instax está como "Consultar" porque no se recibió un precio en los datos iniciales.

## Publicar en Vercel
Puedes subir esta carpeta/proyecto a un repositorio de GitHub y luego importarlo desde Vercel, o usar Vercel Drop si está disponible en tu cuenta.

## Importante
Este proyecto no cobra en línea ni guarda pedidos en una base de datos. El pedido se prepara y se envía a WhatsApp; tú confirmas disponibilidad, cobertura y envío contra entrega.
